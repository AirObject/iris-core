# recall_v2 冻结说明

在任何检索实现修改前逐条手写：50 条虚构固定记忆，66 条自然查询，44 dev／22 holdout；无答案 16 条（dev 10／holdout 6）。没有模板或脚本拼接质量语料。recall_v1 原样保留作回归。

类别可以重叠：换个说法、别名、无答案、问已知的人的未知属性、按参与者召回、近期消息去冗余，另有口语。按参与者类含代词加参与者和概括式人物提示；明确问属性时不能靠返回其他人物要点冒充答案。近期消息来源和 known_memory_ids 两种冗余都覆盖。

同音／近名主体分别是林夏／林霞、周宁／周柠、许舟／许洲、顾岚／顾蓝、程意／程毅、陆遥／陆瑶；同一主体含多种事实，未知属性题不能仅命中人名就算有答案。subjects 中的 aliases 是本人声明的别名，评测器须写入 subject_aliases，而非伪造同名关系记忆。

holdout 以另一组人物和活动为主，只有最终冻结实现与参数后运行一次，不参与维度、前缀、融合权重或阈值选择。作者知道公开 holdout 的内容，因此独立性仍弱于规划者维护的隐藏集。执行者不寻找、读取隐藏集。后续修改标注必须单列真实错误及理由，不能按结果改答案或放宽门槛。

比较计划先冻结：仅 dev 比较无前缀与“为这个问题检索能回答它的个人记忆：”前缀、1024 与 2048 维；在相同查询上比较 FTS 和混合召回。绝对下限、相对最佳候选截断、RRF 两路权重均在 dev 上标定，选择规则保持 `(Recall@8+nDCG@8)/2-无关误返率`，平分优先召回、nDCG、较低误返。M2 参考值不变。报告同时列总体、split 和类别，空分母显示不可计算。
