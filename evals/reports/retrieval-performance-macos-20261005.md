# PR #5 macOS 性能复测（2026-10-05）

Apple M4，macOS-26.6.2-arm64-arm-64bit-Mach-O，10 个逻辑 CPU，16 GiB 物理内存；Python 3.13.15、SQLite 3.53.1、NumPy 2.5.3。

测量代码为合并提交 `25edc97`，`evals/benchmark_retrieval.py`、产品源码和默认参数均与 `8d8f3fc` 相同。两条命令依次运行，未同时运行 pytest 或另一条性能命令。

```bash
uv run python evals/benchmark_retrieval.py --out evals/reports
uv run python evals/benchmark_retrieval.py --default-config --out evals/reports
```

每个规模／dtype 新进程；两种查询分别预热 5 次、采样 60 次。固定种子生成合成记忆与向量，不涉及质量语料；查询 embedding 预生成，不计外部网络。prepare 包含 FTS、向量、候选锚点、去冗余与召回记录提交；HTTP 另含 JSON 和进程内 ASGI TestClient 路径。所有原始结果保留，没有按快慢选择重跑。
