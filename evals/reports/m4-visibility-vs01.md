## 实现与计算

入口支持 shared（默认）、entry_only、entries；列表自动包含本入口。管理 PATCH `/admin/api/entries/{entry_id}/visibility` 使用既有管理员会话、CSRF 和操作记录。入口列表／设置与记忆详情返回可见范围，空交集记忆仍可在管理详情查看。

记忆取全部来源消息入口集合及递归派生依据集合的交集。目标取直接消息来源与所属入口的交集，无来源按所属入口，无所属入口全局可见。所有集合都从当前设置计算。实际集合相同才允许去重／确认／合并，空交集对任何入口均不可见。

`memory_ops.Visibility` 在当前 SQLite 快照内从受限入口出发，用来源索引与递归 UNION 传播限制；不读取正文。全 shared 时跳过来源图遍历。缓存最多 8 个不可变图快照，以数据库触发器更新的随机版本 token 为键；入口、来源或目标归属变化立即失效，回滚不会复用错误快照。来源清除前保留来源链中的入口 ID，避免尚存派生记忆意外变为全局可见。

| 通道 | 处理 |
| --- | --- |
| prepare 相关记忆、人物要点、名字锚点 | 在全文／向量候选截断前过滤，向量相对阈值只使用可见候选；判断后写召回记录时复核 |
| search、include_forgotten、include_goals | 指定 entry_id 时按该入口过滤；省略 entry_id 时只返回全局可见项 |
| 近似去重 R13 | 先过滤，再仅对实际范围相同的记忆去重 |
| 人物关系与目标附带引用 | 不输出不可见的关系依据、目标重复引用和记忆依据引用 |
| 学习材料 | 已有记忆只取本批入口可见项；默认检索参数不变 |
| 学习去重、确认、修正与派生 | 去重／确认／修正要求新旧范围相同；派生写入前复核依据修订号与当前可见性 |
| 整理 | 跨范围不生成合并／矛盾配对或依赖材料，范围纳入内部指纹，写回再检查 |
| persona | 只选全局可见的自我记忆；依据后来私有化的已发布句子停止进入宿主与学习材料 |
| 目标去重 | 确定性与模型候选先限制为同范围，模型返回后复核范围和修订号 |

没有增加模型调用。现有模型调用仍在数据库事务外。`api.py` 未修改：Search.entry_id 字段、令牌入口权限 403 与参数转交仍由 AP 接线；本分支测试直接调用 Retrieval.search。
