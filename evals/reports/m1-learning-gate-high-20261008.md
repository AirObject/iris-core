```bash

  uv run iris eval learning --judge-mode external \
```

没有因限流或超时放弃的批次，本次运行有效，没有触发全部 86 段换目录重跑，也没有按得分选择案例。

两轮分别从正式 round-template.json 复制 manifest.json。每轮每个案例交给一个全新的独立子代理，只提供冻结 scoring.md 与该案例 input（含角色名），另有纯交付用途的加密程序及公钥。代理不知道轮次、学习提示词版本、档位、历史报告或其他判分；每个代理只读本案例材料，不互相交流。两轮顺序进行。

所有逐案例判分以 RSA-OAEP-SHA256＋AES-256-GCM 加密交付。解密私钥仅在调度进程内存及调度者工具上下文中保留，不写入共享文件系统。第一轮在第二轮结束前始终封存；所有代理结束后才把两轮判分明文解封到结果目录。中途校验仅返回格式错误及哈希，不显示判定值。

调度者仅做数组长度、布尔类型、记忆 ID／顺序、重复 JSON 键和材料绑定校验，不改判分。通过产品 `_judgment_errors` 严格校验，最终导出的 JSON 与代理加密前原始字节 SHA-256 一致；172 份 input 逐字段及评分说明逐字节核对正式材料。格式重判次数见下方调度审计。
