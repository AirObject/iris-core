## 检查规则、测试与局限

对应测试为 `tests/test_profile_quality_followup.py`，均为手写机制夹具，不是质量语料。原 v2 路径仍有原有测试；v7 专项通过显式版本运行。

| 检查 | 确定性规则 | 单元／假模型测试 |
| --- | --- | --- |
| 独立讨论 | 只计本条绑定的原始正文、不同消息 ID、不同本地日期，至少一对相隔 ≥30 分钟；枚举所有组合，不受引用顺序影响 | 跨日、午夜连续讨论、顺序与第三条有效依据 |
| 重复和复述 | NFKC＋casefold 后仅留字母数字；相等或包含只算一例；两段均至少 12 字且 SequenceMatcher ≥0.85 也不计两次；明示转发／转引／转述／引用／复述／原话等不计 | 原文副本、标点变体、近似复述、明示转述 |
| 引用副本 | quote.content 可作解释原话，但不计独立观察；任何带 quote 的消息连其自身正文也保守不计次数 | 一条消息两段引语、两条消息引用同一原话、带引用的回复 |
| 报名接龙 | 原始正文含接龙、报名、算我、加我、独立 +1 标志时不计独立观察 | 报名句、接龙条目 |
| 群内说法 | 至少两条绑定原始正文都含 label 原词，且不属于上面的重复／转引／报名；任意两条间隔 ≥60 秒；同人两条 ≥30 分钟，且不能在同一连续发言段中（相邻同人、间隔不足30分钟会连成一段） | 同一分钟、同人短时刷屏、连续刷屏跨30分钟、未绑定消息不能凑数、只有用法且无 meaning 可保留 |
| 作品名 | 标签每个《作品名》必须同时在至少两个合格的独立原始正文中出现，不能借无作品名的另一对满足独立性 | 作品名双绑定、仅一处点名、每个并列作品、午夜伪独立 |
| 性别代词 | 仅 label／meaning 检查他、她、妳、祂以及英语 he／she 等词及相关形式，删除整条；“其他”“吉他”不按“他”误删；不改动原话 | 男女代词、繁体复数、英文、非代词词语、引文不改字 |
| 释义与隐私 | 检查提示词逐个实词核对本条绑定原话／记忆；无依据只删 meaning，保留已支持的说法。引文逐分句检查，含同事／家人／其他群友私事则删整条；生成阶段可先裁安全连续片段 | 既有无依据 meaning 删除测试；候选 v7 确定性检查后再由模型删除隐私条目，调用在事务外，拒绝版不发布 |
| 运行器来源 | Engine 一次加载两份提示词文本；每次调用记录版本和所发文本 SHA-256；run.json、manifest 的 run 和 report 记录同一份实际加载信息。案例间提示词变化会阻止该案例调用 | 两个运行器的版本／哈希／发送文本核对和材料指纹验证 |

这些是可判定的下限，并非独立事件的充分证明。语义复述、无明显标志的接龙、同一活动跨日筹备、不同说法的变体、普通方言是否为本群专有用法、具体词义和第三人的隐私仍交检查模型；没有新增模型调用。代码不读取未选中的消息来补证据，连续发言段只看当前材料，因此无法辨认采样窗口外的刷屏。

保守排除会误删讨论“报名机制”的正常消息、带引用但提出新问题的回复、措辞高度相近的真实重复讨论，以及 label 有变体的独立用例；性别词正则不能完全识别人名／外语词法。没有用覆盖率抵消这些规则。相似度和时间间隔是本轮预览前确定的通用启发式，没有按分数调参。
