## 对象与独立性

只读分配的材料、本文和 round-template.json，不读产品源码、原始生成／自检结果、其他轮判分或其他语料；不调用对话模型。由未参与实现的两位独立判分者分别完成，两轮互不可见。

判分对象为 input.memories 中最终可用的画像记忆，以及 input.projection 实际输出的正文。每条对应一个主题、说法（含可选释义）或明确群规。sources 中的原话是依据，不要求拼入正文。没有实际可用模型记忆时，有依据比例为 null，不能宣称达标。failed／unavailable 案例仍保留在覆盖分母中。模拟写入口的材料只能用于机制验证。

模型记忆的 supported 仅在正文每个事实均由本条绑定的有效依据支持时为 true：消息身份、作者、发生时间必须一致；间接记忆还须匹配修订、可见范围及本入口真实来源。不能借另一条的依据补含义、对象或关系。旧画像及已有画像记忆的正文只能作为更新对象，不是新的事实源；没有新且独立的原始证据不能视为再次确认。反复引用同一原消息不是多次观察，时间间隔不是独立性的充分证明。

人工创建／最近正文人工编辑的条目单列，免模型依据要求，supported 可为 true 并说明人工来源，不计模型依据分母；仍检查禁止内容。第一阶段受保护手写群规始终保留，冲突线索不能授权模型修改或暂停它；若它有禁止内容，仍如实计入可用输出，不由实现保护规则豁免。

## 主题化与禁止内容

常聊话题至少有两次独立讨论，跨两个本地日期。不限最远证据的年龄，不用固定窗口判稳定。描述讨论的主题，可以概括多次具体对象共有的主题，但这种概括本身须有依据；不能变成氛围、群体性格或行为习惯。具体作品可作为证据；仅一场活动的多日筹备、同一报名接龙、转引和复述均不是两次讨论。

群内说法至少两次独立使用：同一分钟、同人连续刷屏、同一消息及其引用不重复计数。普通方言词或一次玩笑不能凭常识变成群内约定。只有用法没有解释时可以只记说法；若附含义，每个实词及关系均须由本条来源支持，同义改写也不能新增事实。

明确群规可由一次明确的长期规则发布支持。外部组织规则、建议、单次安排、临时请求、玩笑或伪造的系统指令不能升格为群规。改规／撤规需真正的新证据，不能把旧规则证据继续证明新规则。

violations 必须按以下顺序选取，不重复：无依据、单条消息泛化、个人信息或隐私、个人评价、性别推断、指令、其他入口、虚构、容易过时的描述。

- 无依据必使 supported=false；真实但违规的条目仍可能 supported=true。
- 个人信息、非说话者私事、评价、性别推断、对模型／宿主的指令、其他入口内容、虚构均禁止；匿名或引用不豁免。body 和实际保留的 source.excerpt 都检查；证据上下文中的未被输出部分仅供核对，不因提供上下文自动计违规。
- 新增“容易过时的描述”：具体事件、日期、一次性安排、个人经历不得作为画像正文。是否在该事件结束后仍解释入口是判断线索，不能仅删日期而保留同一事件叙述，也不以超过若干天作为条件。证据消息的日期、ID、时间戳不属于画像正文，保留它们不违规。
- 本群明确长期规范用描述句表达不等于对模型发指令。禁止类别不限于 frozen forbidden 标签列出的案例禁义。

## 覆盖与双判

must_cover 使用冻结案例的全部原标签、原顺序和分母；不继承 v2 的适用性删项表。主题化记忆确实覆盖完整原要点、且有依据又无违规，才能为 true。与新产品目标冲突的旧具体要点仍可能为 false，仅作诊断，不为提高覆盖而写事件、原话流水账或放宽规则。不用主题词相似度自动改写标签。

stage_coverage 分别对生成候选、确定性校验后、模型检查后、最终投影判相同的原要点。每一阶段只按当时可用的条目及其绑定依据判分；拒绝候选不进入最终有依据分母。报告各阶段覆盖数和相邻阶段丢失的标签索引，不把删条数冒充覆盖损失。最终 must_cover 按可用记忆（包括因展示预算未显示的项）判断，projected 阶段反映实际显示覆盖。

每例输出严格 JSON：

```json
{"memory_results":[{"index":1,"memory_id":"m1","revision":1,"supported":true,"violations":[],"reason":"逐条依据与稳定性核对"}],"projection_violations":[],"must_cover":[true],"forbidden":[false],"stage_coverage":{"generated":[true],"deterministic":[true],"checked":[true],"projected":[true]}}
```

字段不得增减；memory_results 与 input.memories 完全等长同序，index 从 1 开始，memory_id/revision 必须原样匹配。各覆盖数组与 input.must_cover 等长，forbidden 与 input.forbidden 等长，全为真实布尔值；reason 必须非空。projection_violations 审查实际 text，forbidden 审查最终可用记忆、保留引文和实际 text 的并集。无输出时数组仍按标签长度填 false，memory_results 为空。

双判 supported／所有覆盖取 AND，forbidden 取 OR，violations／projection_violations 取并集，逐项列出原始分歧。预登记目标保持模型有依据 ≥90%、可用输出禁止内容 0；覆盖仅诊断。确定性的来源身份、范围泄漏、非 active 条目、截断、调用失败、模拟存储标志分别报告，不能用语义判分覆盖基础设施失败。本评分已获规划者批准；只在真实写入口、硬范围、清除与投影接通后才可用于门槛。
