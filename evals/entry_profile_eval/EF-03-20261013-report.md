1. 有依据分母改为最终可用模型画像记忆（ID＋revision），人工内容单列；来源原话移到 sources，不拼进正文。仍要求每条全部事实有本条依据。
2. 保留两次独立讨论／使用的要求；新增禁止类“容易过时的描述”，包括具体事件、日期、一次安排、个人经历。门槛仍为 ≥90%／禁止0，空分母不通过。

5. 两轮聚合正项 AND、禁止 OR、违规并集，逐项列分歧。现阶段强制 draft_pending_planner_approval、repository_mode=simulation、gate_eligible=false、meets_threshold=null。不能用机制测试宣布质量达标。

## 已完成

- `MemoryProfileRepository` 定义 detached snapshot、事务外调用断言和原子 commit 契约；缺少适配器直接拒绝，没有向旧版本表或普通 memories 写入的后备路径。
- 取材按入库位置的增量前缀，再补有界历史原话／普通记忆的真实来源；不按证据年龄过滤，不采用14天／50条资格规则。不截断正文，不跳过预算外未扫描的游标；首条超预算明确阻塞，后续页可带历史锚点。记录预算、遗漏来源和历史是否完整；含系统提示词的单次请求总预算12000估算token，避免检查时重复绑定膨胀，单次超时上限120秒。
- 生成 new／confirm／revise／retire，逐条校验；两次模型调用均位于快照读取之后、commit 之前。模型失败、检查格式错误、并发冲突均不推进游标。
- 自动 importance 裁剪到69，低于现有免衰减阈值70；新记忆不置顶、event_time=null。没有新增独立证据不能确认。精确相同的主题新建转为确认，同一目标每次计划最多一项。
- 手写保护：revise／retire 确定性拒绝并诊断；允许支持原文的确认，不改变正文、修订或人工重要性。检查步骤同时看到受保护规则用于发现新建条目绕过保护的冲突，不把它们当新事实依据。
- `SimulationRepository` 是无数据库访问能力的测试替身：模拟来源／目标／设置／游标复核、原子写入、回执去重、丢失响应后重放。模拟普通记忆的少量状态变化用于验证接口，不是另一套生产生命周期。
- 新独立运行器沿用原 cases／groups 解析，annotations 不进入模型材料；initial_profile 原文种为受保护人工条目。只提供显式假网关注入的离线适配函数，不提供加载真实模型配置的命令。

## 检查、局限与测试

| 检查 | 当前规则 | 单元／假模型验证与局限 |
| --- | --- | --- |
| 原话与身份 | ref＋field＋via_memory 精确绑定，连续原话可规整空白，引用归原作者；记录全部生成引用匹配数 | 不存在引文、错引用、间接来源修订、引用作者、最小安全摘录；存在率不等于支持率 |
| 话题独立 | 两条独立原消息、跨本地日期且至少间隔30分钟；排除引用／转述标记／报名接龙 | 重复ID、复制、转引、同日、报名被拒；30分钟只作保守反刷屏下限，不是画像证据年龄窗口 |
| 复制与同源 | NFKC＋大小写规整后的实字串包含，或长度≥12且相似度≥0.85；显式原消息身份去重 | 可能误拒短文本、重复的真实用法；隐式改写仍交模型，不能穷尽所有接龙格式 |
| 群内说法 | 原话实际含说法；至少两次独立使用，排除同一分钟／小于60秒、同人30分钟内及连续刷屏链 | 同分钟、同人跨分钟刷屏、独立用法无含义；普通方言是否为群内说法由模型核对 |
| 正文性别代词 | 正文他／她等及英文第三人称代词拒绝，“其他／吉他”排除 | 正文代词、词内字形；仍不能识别所有隐含性别推断 |
| 稳定性与语义独立 | 检查输出必须显式 supported、stable、independent 与原话分组 | 跨日单事件分组、稳定性失败导致删项；模型可能误判，不能宣称确定性已证明语义独立 |
| 隐私 | 模型逐条审正文与实际保留摘录，失败删整项；不自动缩引或重写 | privacy_safe=false 删除；完整上下文只供核对，未经检查的新改写不写入 |
| 含义 | 只能用本项绑定来源；检查逐实词／关系给 source_indices 与布尔结果 | 缺逐项核对或任一false失败；代码校验结构，无法证明中文实词枚举完整性，完整性由提示词约束 |
| 确认 | 新原始身份且与旧来源非复制／非同场；目标确认回执去重，模型再判独立性 | 旧源不能确认、精确重复主题转confirm、确认不加修订、重跑／重复commit不加分 |
| 写回冲突 | 契约要求短事务复核全部目标、来源、范围、人工保护、游标，操作与游标一起提交 | 模拟来源修改／记忆修订／人工编辑／删除／目标修订冲突；新增未读消息不会使原快照失效；真实数据库并发尚待接入 |
| 手写群规 | 始终保留；仅允许真实支持原文的确认；冲突只诊断 | 修改／撤下均拒，检查拒绝相冲突新建；没有暂停投影或人工确认环节 |
| 新格式 | 严格ID／修订／布尔／顺序／数组长度／文件指纹，拒绝额外字段和篡改 | 从严聚合、分歧、覆盖损失、空分母、私聊不输出、无产品自检污染、拒绝候选的伪造上下文不能进入依据 |

采用检查仅删项的策略，含义不支持时本次整项删除，下次可自动仅生成说法。删项原因与各阶段候选保留；真实覆盖损失必须由外判按标签判定，不拿删条数替代。当前没有真实评测或正式外判成绩。

## 待底层及本阶段限制

- 真实 entry 主体、kind/分类、硬入口范围与派生范围、来源／修订关联、原子确认回执、CAS、游标持久化、删除／彻底清除、导出导入：仅接口契约，等待 db／迁移／memory_ops 等文件授权；不能因为模拟器通过就开启生产。
- 普通生命周期继续现行策略；自动重要性上限已在任务侧落实，真实衰减、遗忘／恢复和投影变更通知尚未接入。生产 world=real 等记忆字段由统一写入口落实，模拟状态不代替完整记忆行为。
- RS 的调度、状态、管理；CO 的整理类别隔离；LN／人物模块的主体与材料隔离；普通召回排除、宿主 v1 投影、前端迁移均未改。排队按规划者安排。
- 模拟器的历史锚点仅取有界旧原话，不实现生产主题检索；超过锚点预算的漏材已标记。单条材料或现存画像集合超预算时保守阻塞，需要后续适配器的分页／取材策略，不能静默截断或新增人工审批。
- 模拟投影显示全部有效条目，未冒充宿主500 token／6条预算。多页运行在 trace 保留各页阶段快照；案例外判按最后检查点的阶段集合与最终可用记忆统计。逐页覆盖外判和真实投影预算损失，需要后续真实运行器接入时补充检查点材料，不在本轮宣称完成。
- 候选不足的操作可推进已检查游标，原始消息仍可作后续有界锚点；如果模型／写回失败则整个游标不动。生产中来源清除／范围变化必须即时使投影不可用，不能等待下一次有新消息才处理，本阶段没有伪造这种能力。
