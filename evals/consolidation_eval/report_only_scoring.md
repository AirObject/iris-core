# report_only_v1 判分补充（规划者 2026-10-10 的处理范围变更）

与未修改的 consolidation_scoring_v1.md 一起阅读。冻结语料、expected、JSON 输出格式、双判取不利结论、全部合并指标、保护与相信程度上限检查均保持原样。

本配置的矛盾和依赖复核只报告和标注，正文、相信程度及生命周期不得修改。因此，这两类的 resolution_correct、handling_correct、must_keep 与 source_grounded 根据 actual_actions 中已提交的 report、conclusions、source_excerpts 和记忆 annotations 判断；不因没有改写正文或改变相信程度而判失败。原评分说明中要求补充或纠正的限定，必须在持久化结论或标注中明确落实，泛泛的“待复核”不算完成。旧正文与相信程度的保留本身不代表仍确认旧命题；应核对标注是否具体指出争议、被替代、依据不足或受到否认的范围。

仍须独立检查结论是否由来源支持，是否区分过去与现在、笔误与事实、不同主体、同源复述与独立依据，是否保留时间、数字、否定和条件。不能因为模型自己声称已处理就判通过，不能用报告抵消合并语义失败、保护违规、生命周期变化或重复扣减。保持类无变化时仍沿用冻结说明，不要求额外报告。

合并继续完全按冻结评分说明判断实际保留正文，不用标注补救漏掉关键事实的合并。本补充只落实规划者授权的矛盾／依赖输出范围变更，不重选 broad，也不降低合并要求。
