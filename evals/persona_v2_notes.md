# persona_v2：较长、较丰富背景的公开 dev 时间线（冻结）

本集与 `persona_v2.json` 在独立提交中冻结，供 persona 优化线迭代使用。沿用已经冻结的 `src/iris/prompts/persona_scoring_v1.md`，不修改判分契约。编写基线为 `origin/main` 的 `16904b4`。根据任务中给出的失败**类型**另写全部人物、背景、来源消息和事件；没有寻找、读取或复原隐藏案例，没有复制 persona_v1 的人名、主题和句子，没有用脚本、模板或循环生成语料。全部人物与经历均为虚构，不含真实用户数据，所有 split 为 dev。

共 **5 条时间线、35 个检查点、30 次预期变化**，小 11 次、中 16 次、大 3 次；预期 27 次直接发布、3 次待确认、5 次不生成。另有 3 次管理员追加发布、3 次确认，均不额外计为模型变化；首次设置的 5 个模板也不计。这里是先验期望，不是实际模型成绩、实际发布数量或 M3 门槛结论。

## 格式、运行与计数

没有新增字段、删除字段或改变 persona_v1 的字段含义。继续使用 UTF-8 JSON、`format_version=1`、`initialized_at`、`checkpoint.at`、`expect.generate/change/publication/level/must_reflect/must_not`。`persona_goal` 与 `persona_rules` 均为 null，使用产品默认值。本集使用 README「M3 计划」已经约定的 `persona_edit.append` 和 `persona_confirm`；未使用 `persona_reject`，也未增加新的 op。

1. 每线独立建库，在第一天之前的 `initialized_at` 首次设置。背景按现有 `memory_ops.setup_role` 的句子拆分规则自动成为 self／设定记忆，不再重复 add。它们属于初始模板的快照，不凑之后的五条变化。
2. 所有日期均为 **2027 年、Asia/Shanghai**。每天按 ops 数组顺序在 **22:00** 执行；检查点均显式写为 **23:00**。来源时刻不晚于该次操作。多来源推断可以引用较早的真实摘录，重复的摘录保持相同入口、作者、种类、时刻和原文。
3. event_time 是所述事件的时间，不是入库时刻。未来承诺可以有未来 event_time，但其来源是当天已经说出的约定；到约定日期不自动产生履约事实。更新计时不得使用 event_time 或来源日期替代版本生成时刻。
4. 发布预期沿用基线 README 的评测约定：检查通过的小／中候选直接发布，大候选等待确认（`small_medium_auto`）。本集不设置或改变上线产品的发布策略。若运行环境使用全人工发布，应在仓库外报告实际策略及与本预期的差异，不修改冻结标签或把未确认候选当作当前版。
5. `persona_edit.append` 追加并发布，只有新增的句子是手写；已有正文的来源身份保留。追加不会产生新的自我记忆。PT21、PT22、PT24 的三个称呼／比喻均无记忆依据，自动候选应删去，删除手写内容一律判大。后面的显式确认接受待确认候选；没有待确认候选时按 README 为空操作，不注入预设版本。
6. 更新条件从**实际当前版本的生成时刻**计算，确认不重置生成时刻；管理员编辑的版本从编辑时刻重新计算。每个不同 self key 至多计一次变化。他人评价、他人指令和他人生活不能凑数。状态／计划记录虽不是合格的 persona 内容，仍是本输入中的 self 记忆变化；是否触发生成与是否可收录是两件事。
7. 下表按预期成功路径复算：直接发布后以该检查点为新起点；待确认时仍用旧当前版，确认后改用被确认候选**原来的生成时刻**。三个确认都排在当天新增记忆之前，因此确认后新增的记录仍待吸收。表中没有在确认日额外计一次生成。
8. 若前面实际拒绝、超时或没有发布，后面应按真实当前版重算并记录偏离，不能为了匹配表格强行发布或重置时钟。本集预期每次生成都有实际的新内容可吸收，但不要求把 35 条 self 记忆逐条搬进 persona。
9. `generate=false` 的五个检查点仅核查不触发、当前版保持等行为，没有新候选可逐句判分。其余 `must_reflect`／`must_not` 检查新候选的全文；30 次预期变化包括待确认候选，与“已自动发布”不同。
10. 评分只使用每句实际绑定的有效记忆与来源。表中的例子与参考项不是补充依据；背景、较早 persona 和其他句子的引用也不能帮本句补齐细节。单日直接说喜欢、认为或觉得自己怎样，仍只能作当次场景的认识。新的独立日期可以支持有限倾向，但不能追溯地让早期泛化变正确。

## 失败类型覆盖对照
