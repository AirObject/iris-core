首轮参数暂设绝对下限 0.5、相对阈值 0.85、两路等权。1024 维无前缀的 jieba 混合结果为 Recall@8 0.9461、nDCG@8 0.9372、无答案误返 0.70。该轮完成前缀对照后，2048 维取向量遇到 HTTP 429，中断，没有完整报告；上述数字来自进程输出，不冒充完整比较。成功向量已缓存，失败轮的用量没有完整汇总，不能计为零。

dev 错误检查发现漏滤“会”等虚词，以及活动／人名命中被当作所问属性的答案。增加查询专用停用词和有限的明确属性证据规则（生日、费用、卫生间、保修、过敏、籍贯、住址、职业），不使用生成模型或语料 ID。规则不是通用语义理解，对未覆盖的属性／说法仍可能误返；需隐藏集检验。无答案标签、样本和门槛未改。

随后仅在 dev 比较 1024／2048 维、无前缀／“为这个问题检索能回答它的个人记忆：”。网格为绝对下限 0.35／0.45／0.55／0.65，相对最佳余弦比例 0.75／0.85／0.95，向量 RRF 权重 0.5／1／2，全文权重固定为 1。按冻结的综合分数选择。维度从服务商实际请求，不截取 2048 维冒充 1024。

缓存键含端点、模型、请求维度和完整 embedding 文本。单路、请求间至少 1 秒取新向量；错误时保留其他已完成向量，缓存数据库保存本轮之后的调用记录。复用仅按同输入缓存，不按得分挑选。

## 测试与工程方法

Python 3.12 和 3.13 使用 `data/venv312`、`data/venv313` 两个独立环境。模型评测运行时不改源码、迁移或重建其虚拟环境。
