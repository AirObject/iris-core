# 短词与短名字 v1 冻结说明

2026-10-06，在 PR #5 第四轮任何实现或测试修改之前逐条手写并单独提交。全部人物、经历和场景均为虚构；没有用脚本、模板或模型批量生成，不猜测、不寻找、不读取规划者隐藏集。

共 16 条固定记忆、16 条 dev 查询：12 条有答案、4 条无答案。质量标注随查询一起冻结，不能依据复测结果增加答案或降低相关等级。

- ST01—ST04：两字关键词的 search，带人物筛选。S04／S15 的近名人物用于检查筛选不能混淆。
- ST05—ST08：两字关键词的 search，不带人物筛选；四条均只有一个已记录的直接相关事实。
- ST09—ST12：两个字的人名的“是谁”类问题。S09、S11 的名字只在 about 中，S10、S12 只在正文中；不是记忆说话人。ST11、ST12 的被问者均不在当前参与者中。S13 为近名干扰。
- ST13、ST14：两字关键词无答案，分别带／不带人物筛选。其他兴趣不能当作所问兴趣的答案。
- ST15、ST16：短名字无答案，分别为已登记但无记忆的主体、未登记的名字。没有任何身份材料可用于作答。

本集验证不足三个字符的词项不应因 trigram 丢失，且姓名可以通过涉及人或正文产生候选。它不要求用人物的其他事实冒充未知属性的答案。混合检索与无 embedding 的全文路径均需验证；不会按查询措辞加入话题词表或特判。
