# 对话中准备 v1 冻结说明

2026-10-04，在第二轮检索改动前手写并单独提交。33 条固定记忆、24 条查询，全部为 dev；18 条有答案、6 条无答案。每条查询明确写 `text: null`、`participants: null`，覆盖私聊、群聊、直播。没有用脚本、模板或模型批量生成语料。

正文和近期消息均为虚构。记忆包含相近名字、相近主题、同一人的其他事实；相关性仅标注能支持当前问题的记忆，人物要点不自动成为相关标注。C23、C25 的全部证据在返回的近期消息内；T13 另用 known_memory_ids 检验已知记忆去冗余。无答案包含未知生日、租金、开播安排、设施与借用情况，以及信息已在近期消息中的情形。

入口类型由 entry_kind 指定。Iris 的本人别名“小鸢”以及其他主体别名在 subjects 中显式给出；人物身份以固定语料的主体为准，不模仿真实账号。名字歧义的多主体边界由确定性测试覆盖。

本轮所有公开召回集都按 dev 使用，v2 原 split 留作历史来源标记，不作独立验收。标定合并三个集合的查询指标，但每个集合使用独立数据库，避免混入其他集合的记忆。选择规则仍为 `(Recall@8+nDCG@8)/2-无关误返率`，平分依次看召回、nDCG、低误返；维度和前缀保留第一轮对照结果，本轮重标定绝对下限、相对比例和融合权重。拒答问题只报告，不增加话题规则。规划者另用不可见的隐藏集验收。
