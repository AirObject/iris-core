# ADR-0054：统一 Observation 上下文与有界批量总结

状态：Accepted（2026-09-08 用户批准方向及运行默认；实现与本地分段复验完成）。

## 背景

宿主不能逐条调用模型判断记忆价值，需要保留范围内原始信息、即时提供尚未总结的上下文，再批量识别相关消息。现有 Observation 已提供无模型写入、时间、Scope、幂等和删除；独立环境库会复制这些责任。

## 决定

沿用 Observation 作为统一原始事件层，添加兼容元数据并提供有界上下文读取。摘要使用 Episode，不把模型输出放进 Observation 原文或冒充外部效果。背景消息的相关性判断发生在有界批次，分组引用真实消息，使用过的背景保留来源与隐私约束。

自动总结显式开启，按数量或等待触发；原始读写不依赖模型。背景 Observation 默认 30 天可配置；有效引用与 Hold 阻止普通到期删除，主动遗忘继续优先并失效派生摘要。旧直接接入保留，不默认引入新的短期删除行为。

调度、处理与提交使用既有 Outbox/Scheduler/Provider 治理，补齐 Worker 与 Embedded 的周期推进；批次成员和结果持久记录以支持重启、并发、空结果和删除重验。

## 与既有决定的关系

延续 ADR-0001/0004/0005 的权威来源、修订和删除优先，扩展 ADR-0009/0011/0013/0019 的观察、窗口和巩固，不修改其已确认外部效果规则。摘要不是额外独立证据；接入继续遵守 ADR-0053 的公共入口。

## 代价与验收

增加观察元数据、处理账本、实时查询和配置接线；保护交互窗口、防止全量流造成无界存储/模型工作。完整实施与验收见[实施说明](../development/observation-context.md)。Accepted 表示采用设计，不表示功能已完成或生产验证通过。
