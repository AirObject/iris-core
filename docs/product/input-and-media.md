## 4. 输入与接入规则

<a id="source-line-143"></a>

### 4.1 保留原始语境

输入保留来自哪个平台、哪个入口、谁发送、角色身份、原始正文、引用内容、多媒体文件和理解结果等信息，允许场景扩展属性。

群聊需要保留群与发送者；直播间需要区分观众、自身主播、协同主播等；游戏观察与执行反馈保留各自特有信息。引用者不自动等于被引用内容的原始作者。

建议为输入记录外部事件标识、事件发生时间、系统接收时间和关联标识。晚收到的旧事件仍是旧事件，不因为接收时间更新就覆盖较新的事实。

<a id="source-line-151"></a>

### 4.2 自身输出和行动反馈

自身输出、行为和结果经薄兼容层回流，参与正常缓存和学习。意图、拟生成内容、已发出的内容、执行返回结果必须能够区分。

“系统曾经表达了一个猜测”可以构成发言经历，但不构成猜测本身获得独立证据。普通行动反馈可成为认知材料，不使本系统获得执行监控职责。

<a id="source-line-157"></a>

### 4.3 输入与管理操作分离

普通发言、回复准备、记忆查询、使用反馈、当前状态更新、目标注入和目标状态操作，具有不同接口含义。

所有外部内容都可以成为学习材料，不意味着正文具有系统控制权限。用户在消息里写“敏感信息无法学习”，不能触发 provider 拒学删除；普通聊天也不能读取审计日志或修改 persona 监督配置。

<a id="source-line-163"></a>

### 4.4 专注期的输入例外

专注梦境仅接收可进入缓存的原始输入；回复准备、召回、状态操作、目标操作和使用反馈等不得作为“输入兼容”偷偷排入梦境序列等待执行。输入接收回执标明已暂存而未学习，所有非例外业务调用明确返回正在梦境中。Web只读状态保留独立通路。

## 5. 多媒体理解、隔离存储与清理

<a id="source-line-171"></a>

### 5.1 理解优先级

在正常处理阶段，外部已提供理解结果时复用，不重复理解；缺少结果时由本系统补充。保留原始文件、理解文本和理解来源的关联。专注梦境期间只保存输入与已有结果，缺失理解延后到该入口回流正常处理时进行，不因附件到达触发额外模型请求。

判断应针对每个媒体对象，不能因为同条消息的一张图片已有解释，就把另一段未理解音频当作已处理。空文本、失败结果和部分解释的具体判定条件属于接口待细化事项。

<a id="source-line-177"></a>

### 5.2 媒体理解被拒绝

媒体理解阶段发生敏感拒绝时，将该媒体对应的可用理解信息替换为固定文本：

> 敏感信息无法访问

同时标识理解状态为被拒绝。它是处理占位信息，不是对媒体内容的事实描述。

这不等于整轮记忆学习被拒绝，不删除整条消息或同一轮其他输入，不要求立即删除媒体文件。后续学习可使用其余信息，但不能把无法访问的媒体当成已理解的证据，也不能通过再次回退理解自动绕过拒绝。

<a id="source-line-187"></a>

### 5.3 文件与业务引用

文件保存于特定隔离文件夹，通过索引关联正常缓存、历史辅助段、梦境暂存序列、学习暂存内容、来源快照和记忆。多个对象可以共享文件，不要求复制二进制内容。

遗忘记忆仍是存在的业务对象，其引用可以保护媒体。删除某条记忆不删除其他业务对象持有的共享媒体。

成功轮转、普通失败轮转和敏感拒学清理会释放被移除内容拥有的引用；保留下轮尾部、后续待处理输入和共享来源的引用仍有效。文件本身由统一定时任务清理，不另设拒学即时删除路径。梦境序列向正常队列移交时保证引用连续，不能在中间空窗被误清理。

<a id="source-line-195"></a>

### 5.4 无引用清理

定时清理完全没有业务引用的文件。正在上传或处理中尚未完成绑定的文件，建议使用明确的处理中状态避免竞态误删，具体保护期由工程配置决定。

仅被审计日志引用的多媒体，对业务引用检查视为没有引用。日志不保护该文件，也不向 agent 暴露这份审计引用。开发者日志中的媒体指针因此可能失效，不承诺审计附件永久可播放。

学习成功但未生成记忆的缓存，没有独立的媒体长期保留规则；其引用随正常缓存流程释放，再由统一清理处理。
