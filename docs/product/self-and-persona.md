## 12. 自我认知与稳定 persona

<a id="source-line-560"></a>

### 12.1 开放的自我认知

自我认知不预设内容类别和数量上限。身份、经历、性格理解、偏好、价值观、关系、能力与限制、习惯、长期方向等均可包含。

短期活动与情绪在概念上也是自我信息，但其当前值由外部状态通道管理。内部可以从外部输入学习“我曾经处于某种状态”或长期倾向，不因此有权覆盖外部报告的当前值。

没有内容上限不等于资源无限，也不取消遗忘机制。自我认知可以随着经历演化，初始设定不是另一套不可变的角色资料库。

<a id="source-line-568"></a>

### 12.2 初始化自我

Web 初始启用引导由外部设定初始自我。可以提供详细身份、少量初始认识，或不预设身份；这些只是初始认知材料多少不同，所有角色都可以随后通过经历形成自我。

初始背景故事保留“外部设定”的来源身份，不伪装成系统运行之后亲历的事件。无预设姓名仍需具有唯一内部角色标识。

<a id="source-line-574"></a>

### 12.3 persona 的内容与监督

persona 是统一且相对稳定的自我摘要，不是全部自我认知，也不是每个入口一份独立人格。它包括适合注入上下文的自我理解与表达风格。

生成目标由外部管理，默认目标是“维持稳定的发言风格，并充分认识自我”。Web 初始化配置目标及该路径的监管 prompt；监管 prompt 约束提炼方式与变化幅度，内部 agent 不自行改写这些监督要求。

<a id="source-line-580"></a>

### 12.4 更新时机

稳定 persona 的常规更新只在梦境阶段进行，频率很低。日常消息、普通学习、当前状态变化或一次回复准备，不即时重生成 persona。

初始化需要形成首份可用摘要，建议在引导中执行一次首次梦境／认知整理；这属于首次建立摘要，不引入按请求重写 persona 的常规路径。

梦境基于当前自我认知生成候选摘要，按监管 prompt 检查变化并发布。具体梦境周期、变化限制表达方式、摘要长度和候选不通过时的处理需配置。

<a id="source-line-588"></a>

### 12.5 来源变化与摘要滞后

建议 persona 保存生成时间、监督配置标识和主要来源记忆。相关记忆被删除、遗忘或修正后，摘要等待后续梦境整理，不因一次查询就同步重写。

因此，旧摘要可能暂时含有已经被质疑的自我描述。这是低频整理的可见滞后，不应声称它反映了全部最新认知。建议给外部提供生成时间及待复核标记。

低频发布规则不取消内部纠正认知的权限；纠正内容可以先进入记忆，稳定摘要在下次梦境吸收。
