# 小任务模板

状态：待批准／契约已批准，待实现／已批准进行中／实现完成，待验收／已完成／受阻（填写实际状态，不以文档或工具链检查替代实现进度）。

## 目标与授权

说明一个可验收的行为、用户授权范围与完成后停止点。若是建议任务，明确待批准，不自动执行。

## 起始仓库状态

工作目录、分支、HEAD、用户已有修改、生效的AGENTS及override关系；实现和工具链实际存在情况。

## 必读与依赖

从 [文档索引](../INDEX.md) 选择最少相关主题、[代码规范](../../CODING_STANDARDS.md)、模块公开契约、共享事务／权限／配置边界，列出真实链接。不要粘贴整份设计。说明已定规则、候选与缺失决定；冲突列双方原文位置及影响。

## 修改范围与不做的内容

列出允许文件或目录、必要运行资源、测试范围、明确排除项和用户已有改动的保护方式。不为凑目录创建空实现。

## 验收与验证

按正常、边界、失败／恢复和权限行为写预期；只引用当前实际存在且核实可执行的检查命令。没有工具链时说明待建立，未执行步骤不得写通过。原文编号可用于此文档追踪，不写进实现、注释、测试名、日志文案或运行时prompt。

## 停止与交付

写明依赖未批准、冲突或不可安全合并时的停止范围。完成后报告实际差异、执行结果、未验证事项；由 [CURRENT_TASK.md](CURRENT_TASK.md)记录当前任务，在切片完成节点简短更新 [STATUS.md](STATUS.md)。[整理报告](ORGANIZATION_REPORT.md)仅保留历史，不要求每个代码任务重做逐节哈希、全文还原或全量覆盖映射；规则变动只同步受影响的原文、视图与相对链接。保留审查差异并停止，不自动进入下一任务。
