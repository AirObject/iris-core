# 小任务模板

用于更新[CURRENT_TASK](CURRENT_TASK.md)，保持约一页，不追加历次全过程；批准状态以现行契约为准，实现进度写在工作记录。

## 目标与授权

一个可验收目标、用户授权和实际状态；建议及待批准事项不自动成为实现授权。

## 基线与范围

目录、分支、HEAD、已有修改及保护方式；链接[索引](../INDEX.md)中本任务涉及的现行正文，列明允许修改范围及排除项。涉及实现时完整阅读[代码规范](../CODING_STANDARDS.md)。

## 阻塞与验证

仅列影响本任务的未批准决定或真实冲突；记录实际检查、对应版本、结果及未验证事项。验收条件链接正文，未执行不写通过。

## 停止点

完成授权工作、必要记录及交付后停止；[STATUS](STATUS.md)仅在验收节点记录里程碑和版本证据，不自动开展下一项工作或提交／部署。已提交历史用Git定位，未提交独有信息不得丢失。

规则在所属现行正文唯一维护，其他文件只更新受影响导航；[冻结原始文档](../reference/README.md)仅供设计和审核参考，不直接约束实现，不再修改或同步。整理报告不作日常必读。
