## 目标

建立统一配置模块中“参数定义与只读注册表”的一个最小内存契约：参数元信息可查询、重复注册被拒绝、未知键查询明确失败，调用方不能修改已注册定义。仅证明这一小块公开行为，不宣称统一配置模块已经完成。

权限、生效方式、校验依赖等在本任务中仅作为参数定义的元信息，不实现权限系统、跨参数业务校验、配置热修改或激活执行流程。

选择依据：仓库目前没有实现或工具链。[原架构实施顺序](../architecture/implementation-options.md#source-line-1202)把统一配置能力放在早期；注册表可以先界定参数责任，范围小于完整配置快照／持久化／热激活，更不包含完整Provider和日志模块。
